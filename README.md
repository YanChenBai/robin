# 知更鸟 · Robin

Windows 系统音频串流到 Android 手机。桌面使用 GPUI Kit，手机使用 NativeScript Vue 3 + Vite，Rust 负责加密传输与 Oboe 原生播放。仅提供深色主题。

## 开发

需要 Rust MSVC 工具链、Vite+、Android SDK、JDK 17 与 Android NDK。手机首版支持 Android 8.0 以上的 arm64 设备。

```sh
vp install
rustup target add aarch64-linux-android
cargo install cargo-ndk
vp run desktop
vp run mobile:dev
```

`vp run mobile:build` 使用优化的 release 配置编译 Rust Android 音频库，并生成调试签名 APK；开发运行也使用优化的原生库以减少实时播放开销。构建与 NativeScript 启动脚本位于 `scripts/`，使用 TypeScript 并由 `oxnode` 执行。手机构建使用标准 Vite 8 的 CLI，工作区其他工具和所有开发命令仍由 Vite+ 管理。NativeScript 的 Vite 配置位于 `apps/mobile/vite.config.mts`；脚本自动定位 Windows 用户目录下的 Android SDK，也支持 `ANDROID_HOME` 和 `ANDROID_SDK_ROOT`。

`vp run desktop:build` 构建 Windows 桌面正式版，输出位于 `target/release/robin-desktop.exe`。

`vp run mobile:release` 构建并签名安卓正式版，输出位于 `apps/mobile/platforms/android/app/build/outputs/apk/release/app-release.apk`。首次构建自动生成本机签名，保存于 `%LOCALAPPDATA%/Robin/signing`，后续构建复用；备份时需保留整个签名目录。正式版使用不带调试器的 NativeScript 运行时，并压缩 JavaScript、移除源码映射。正式签名与调试版不同，首次从调试版切换需卸载旧版，重新配对电脑。

安卓 APK 只打包 `arm64-v8a`，与 Rust 音频库支持的架构一致。构建配置先清空 NativeScript 默认 ABI 列表，避免同时打包 32 位和模拟器运行时；原生库在 APK 内压缩，安装时由 Android 解压。

Android 启动图标原图为 `apps/mobile/assets/robin-icon.png`，背景为透明 RGBA。替换原图后需同步更新 `apps/mobile/App_Resources/Android` 中的各密度图标及自适应前景，再运行 `vp run mobile:build`。普通图标预先铺上白底；自适应头像铺满中央可见区域，由启动器裁切外侧发丝，并由 `#FFFFFFFF` 白色背景层承托。

## 连接

1. 启动电脑上的 Robin，默认跟随系统输出设备；也可固定选择耳机或音箱，串流期间能切换，选择会在重启后保留。
2. 打开手机 Robin，默认自动开启接收并尝试连接已信任的电脑。
3. 首次连接可在电脑点选发现的手机，也可在手机「播放」页的手动连接添加电脑 IP 和端口（默认 `4212`）。手动地址输入仅在手机提供。
4. 核对两端连接代码，在手机允许播放；可勾选记住电脑并自动连接。

两端统一采用黑色背景与紫色强调。桌面使用 480 宽的固定窗口，底部页签切换「播放」与「设置」：播放页以无卡片区域展示当前会话与真实采集音量，下方包含声音来源、附近手机、常驻连接详情和手动连接地址；设置页提供开机启动和关闭窗口后继续运行。桌面使用 GPUI Kit 内建的页签、选择器、开关、进度指示和标签，动效遵循系统减少动画设置。

手机保留「播放」与「设置」两页；播放页将电脑信息与实际 PCM 波形、播放控制合并为无外框区域，未连接时显示手动连接表单，下方保留电脑记录和连接详情小卡片；按钮使用原生矢量图标，连接过程中显示原生加载动画，接收开关、启动偏好与缓冲位于设置页。底部以播放和设置图标导航，两端使用淡灰色边框。

手机的每台电脑自动连接偏好保存在应用私有目录的 `connections.json`，接收关闭或电脑未连接时也能修改。设置提交后先保存，再同步运行中的接收服务；保存失败在页面显示错误。重启应用、重新开启接收仍沿用本地偏好。

桌面默认关闭窗口后留在系统托盘，串流与连接接收继续运行。点击托盘图标恢复窗口，右键菜单可断开连接或退出；设置页也提供退出按钮。开机启动默认关闭，开启后在当前 Windows 用户登录时以 `--background` 启动。桌面偏好保存于 `%LOCALAPPDATA%/Robin/preferences.json`；固定来源被移除时回退到跟随系统默认输出。

自动发现使用 mDNS，手机接收端口为 TCP `4211`，电脑接入端口为 TCP `4212`；音频 UDP 端口由加密控制会话协商。允许 Robin 通过 Windows 防火墙的专用网络规则。

电脑记录保存于手机应用私有目录，关闭接收或重启应用后仍可查看。自动重连由手机端发起，电脑端在会话结束后等待手机重新连接，避免双方同时重试。手机连接失败时按 3、6、12、24、30 秒逐步延长重试间隔，成功后恢复初始间隔。手机在接收服务中发现电脑，优先尝试与已信任指纹匹配的局域网地址，并保留已保存地址作为备用；实际握手仍须验证指纹，成功连接后才更新记录。电脑 IP 变化后可以自动找回；网络不支持 mDNS 时仍可手动连接。此功能需同时更新桌面和手机，旧桌面不广播指纹时继续使用保存地址。旧版本记录首次重新连接后补全地址。允许一次后保存电脑授权，断开或关闭接收后再次连接同一身份无需重复确认。主动断开会停用该电脑的自动连接，但保留授权；自动连接偏好与授权分别保存。

手机支持后台/锁屏播放、通知栏与媒体按键暂停/继续。暂时失去音频焦点时暂停输出，恢复焦点后继续；永久失焦后由用户点击继续播放。接收与重连运行在原生服务中，独立于手机页面生命周期。

控制协议已升级到 v2，电脑与手机需要一起更新。两端主动断开都会同步原因并确认；电脑保存断开屏障，阻止迟到的自动重连，只有用户再次点击连接才解除。消息流程、会话标识、后台缓冲策略和真机验证清单见 [连接协议](docs/connection-protocol.md)。

桌面图标复用手机原图并带透明圆角；替换原图后需同步更新 `crates/robin-desktop/assets/robin.ico`，再构建桌面程序。手机媒体通知和系统媒体中心也使用 App 图标作为封面。

## 验证

```sh
vp check
vp run mobile:check
vp run rust:check
vp run rust:test
vp run desktop:capture-smoke
```

当前没有 JavaScript 单元测试，`vp test` 会报告没有测试文件；传输、播放与重连测试使用 `vp run rust:test`。采集探针验证 STA 调用方能枚举音频设备，并将真实 WASAPI 音频发送到本地 UDP 接收器进行认证解包。

## 延迟

当前使用 rushaudio 1.1.0 的 PCM 数据包格式，48 kHz 双声道，每包 2.5 ms，接收缓冲默认 20 ms，可在播放中调节为 5–100 ms。手机进入后台时临时采用至少 50 ms 的自适应缓冲，返回前台恢复用户设置。该版本的 Opus 分支没有真实编解码实现，因此首版使用 PCM。

接收排序队列及时向 PCM 队列供给完整音频，手机预填充目标缓冲与一个回调的帧数后，由实际音频回调驱动消费。欠载时重新缓冲，并以 1 ms 淡入淡出降低硬切换的爆音。

自适应缓冲默认关闭，使用固定接收缓冲。开启后，在播放欠载或迟到时每次增加 5 ms，稳定十秒后每次降低 1 ms，回落到用户设置的下限。Android 输出缓冲从双 burst 开始，硬件欠载时逐步增大。

发送调度停顿不再跳过未发送包的序号；实际序号缺失、迟到和播放欠载仍在手机连接详情中分别显示。

缓冲与加密收发测试通过不代表真实手机播放已达到延迟目标。手机显示的是基于采集周期、网络 RTT、实际 PCM 队列和输出缓冲的估算值；目标缓冲已体现在 PCM 队列中，不重复累加。10–30 ms 的端到端目标仍需真机测量，蓝牙输出会额外增加延迟。完整方案见 [设计与技术记录](docs/robin-plan.md)。
